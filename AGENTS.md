# Portfolio Project Instructions

## Project
Personal portfolio for Aman, a frontend developer focused on immersive digital experiences.

## Technology
- React 19
- JavaScript (JSX), never TypeScript
- Vite
- Tailwind CSS 4
- GSAP and ScrollTrigger
- Motion
- Lucide React
- React Router

## Design Direction
Dark Editorial.

### Design Tokens
- Background: #0B0C0E
- Primary text: #F1EEE7
- Accent: #C4F56A
- Surface: #141518
- Muted text: #858585

### Typography
- Space Grotesk: Display
- Inter: Body

## Design Principles
- Premium editorial aesthetic.
- Strong typography and intentional whitespace.
- Asymmetric layouts.
- Subtle, purposeful animations.
- Responsive desktop and mobile layouts.
- No generic templates.
- Avoid excessive gradients and glassmorphism.

## Development Rules
- Inspect existing code before editing.
- Use reusable React components.
- Keep components maintainable.
- Use GSAP for complex animations.
- Respect reduced-motion preferences.
- Avoid unnecessary dependencies.
- Never introduce TypeScript.
- Never remove working functionality without permission.
- Test builds using npm run build.

## Project Assets
AURELIS screenshots are stored in public/images/.

AURELIS is the flagship portfolio case study.
Present it accurately as a project developed by the portfolio owner.
